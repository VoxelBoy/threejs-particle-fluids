Three.js Particle Fluids — Perf bench report

No baseline loaded — showing absolute numbers only.

Each scene steps at 60 fps; one frame is one SimLoop.step, which runs every substep as a single GPU compute pass. GPU ms/frame is that pass's duration from timestamp queries — the number to compare between runs. Wall-clock runs from calling step until the GPU reports the frame done, so it adds CPU encoding time and scheduling noise. Frame columns show the median (p50) over the measured frames, with the p10 – p90 spread beside it. Bars show each scene's cost relative to the slowest. Baseline deltas compare GPU p50 when both runs have it, wall-clock p50 otherwise.
